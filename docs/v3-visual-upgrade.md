## 素材與可重建來源

- `dist/assets/env`、`car`、`vfx`、`ui`：此次新素材。
- `dist/assets/manifest.json`：尺寸、幀數、fps、循環、圖集格子說明。
- `scripts/generate-art.py`：固定亂數種子生成環境、材質、序列幀、美術字；這是可編輯的來源，沒有宣稱提供不存在的PSD/AE/EmberGen專案。
- `scripts/generate-marks.py`：標線/箭頭/起始棋盤/數字圖集，8px安全邊。
- `scripts/generate-buttons.mjs` + `scripts/outline-buttons.py`：按鈕及向量外框。外框使用本機Microsoft JhengHei Bold字形，發布包不含字型檔。
- 圖像重建需要Python的Pillow、NumPy、fontTools。轉外框需要Windows的msjhbd.ttc；如在其他平台重建，請指定有合法使用權的中文字型。
- PNG透明貼圖採straight alpha並由Three.js一般混合處理，避免雙重預乘；加法圖集使用黑底。normal與ORM標為線性色彩。

## 發布與檢查

```
npm ci
npm test
npm run build
npm run test:release
node server.mjs release 4174
```

GitHub Actions自動執行以上測試與打包後，發布`release/`。生成素材已提交，CI無須Windows字型或Python。

發布包約1.61 MB、JavaScript約552 KB（gzip約145 KB），低於文件2.5 MB圖檔與2–5 MB整包目標。建置時會印出實際大小。

29項玩法/音樂測試、4項發布包測試（包體預算、外框/三態、合併車體界限、圖集尺寸）。瀏覽器已跑過起步、爬牆、撞毀、結算，檢查WebGL編譯與圖檔載入；小螢幕開始/結算無捲動。

## 明確保留的後續項目與驗證限制

- CAR-01官方GLB：沿用原程序化車型，未猜測或替換官方車模。
- P2熱浪屏幕扭曲、輪胎煞痕、尾燈拖尾、獨立載入/結束背景圖、社群OG圖：未在此版導入；既有風線、霧流與載入狀態可正常工作。
- Bloom採自製輕量半解析度實作，並非引入完整UnrealBloomPass；未將此差異誤報為完全逐項相同。
- 操作鍵SVG外框單檔約數KB至數十KB，中文輪廓比文字大；以整包預算控制，未宣稱每檔均小於4 KB。
- 未取得中低階Android實機，不能聲稱實機60 FPS或最低30 FPS已達標；已提供自動降階機制，仍需實機驗收。
- 未指定廣告投放平台，因此不加入MRAID或單檔base64封裝，CTA繼續開啟原授權網址。
