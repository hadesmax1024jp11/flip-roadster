# FLIP — 飛行電動車 V1

版本：`1.0.0` · 發布標記：`v1.0.0`

V1 包含銀白電動跑車、玩星派對 Logo 跑道、固定 9:16 畫面、頂部精簡 HUD，以及修正後的曲面接觸與脫牆判定。

Three.js 0.180.0 遊戲玩法複刻，參考 https://tsuyatt.com/games/wall-flip/ 。場景、車輛模型、介面和物理邏輯重新撰寫，並非原版原始碼或素材的移植。

## 啟動

在此資料夾執行 `npm start`，開啟 http://127.0.0.1:4173 。不需安裝套件。請使用 HTTP 伺服器，不要直接雙擊 index.html。Three.js 已附在 dist/vendor，字型載入失敗會使用系統字型。`npm test` 執行物理測試。

## 原版分析

核心循環：前進加速 → 沿反曲牆爬升 → 吸附通過倒掛區 → 車頂朝下飛出 → 單側噴射翻轉 → 雙側噴射減速 → 輪胎落地評分 → 重試。

四個操作分別為空白鍵前進、X 吸附、左右方向鍵噴射；手機可同時按住多個畫面按鈕。原版操作說明指出左右噴射器讓車輛繞縱軸翻滾，推力隨車體方向改變，因此倒掛時同時噴射會加速向地面墜落。吸附和噴射共用壓縮空氣。評分包含翻轉、柔和程度與水平程度；多圈可追加分數。原版畫面以低多邊形車輛、反曲牆、數值 HUD 和大型觸控按鈕構成。

此版保留上述循環，改用繁體中文和霧綠試驗場視覺，加入 P 暫停、R 重來、簡易音效與本機最佳紀錄。物理為 120 Hz 固定步長的簡化剛體模型：牆面階段沿參數曲線約束，空中階段計算重力、局部向上的推力及翻轉角速度。不是通用車輛懸吊或完整接觸求解器，也不宣稱原版參數逐值一致。

## 操作提示

按住空白鍵與 X 到車輛倒掛離開牆面；放開 X，短按左或右噴射約 0.65 秒。輪胎逐漸朝下時，同時噴射減速。太晚煞車、車身過度傾斜、吸附中斷或撞牆會失敗。

## 程式結構

- dist/game.js：Three.js 場景、車輛、攝影機、輸入、介面與音效。
- dist/physics.js：軌道、飛行、碰撞和評分，可獨立測試。
- dist/style.css / index.html：響應式介面和觸控控制。
- tests.mjs：起飛、脫牆、推力方向、空氣消耗與著陸測試。

所有模型使用幾何圖元建立。Three.js 的 MIT 授權見 dist/vendor/LICENSE。

## 修正版（9:16）

遊戲以固定 9:16 容器等比例顯示；寬螢幕置中留邊，HUD 與操作區重排。曲面接觸高度增加到 0.84，避開車輪有限半徑與軸距造成的穿透。撞牆判斷使用車體角點及輪胎周緣，並限制在跑道實際寬度。脫牆不再直接鎖定失敗，最終以實際撞擊和著陸狀態判定。新增全曲面幾何檢查、完整成功飛行、脫牆後救回與跑道邊界測試。

### 脫牆接觸修正

未按吸附時，從曲面脫離仍可能保持支撐接觸。新增車體接觸投影及向牆速度消除，在真正離開接觸範圍前不將既有接觸當成新撞擊。只按前進會脫牆掉落，提示明確要求 X 吸附；真正離牆後再次撞擊仍判失敗。新增不同時間步長及不同放開吸附角度的回歸測試，共 11 項通過。遊戲與物理模組使用 v3 資源網址避免載入舊快取。

## 車輛與跑道品牌素材

車輛改為參考圖的銀白楔形電動跑車，以程序化 Three.js 幾何建立斜背輪廓、黑色全景玻璃、貫穿式細頭燈、深色輪胎與金屬輪圈。模型程式位於 dist/roadster.js。加速直線跑道的三處標誌使用使用者提供的原始 Logo（dist/assets/party-logo.png），以透明貼圖貼在跑道表面。新模型頂點已沿完整曲面檢查，未穿入跑道。

## 滑翔與四輪噴射更新

車輛離牆後保留向前動能；車身翻正且有前進速度時提供滑翔升力。左右同時噴射會抑制垂直速度，接近水平滑行；放開後下墜，空氣耗盡則無法維持懸浮。車底共有四個輪位噴口，左、右各控制前後兩個。地面與跑道延長以容納滑翔距離。物理測試共 13 項，包含三種時間步長的懸浮及動能驗證。

## 輕鬆操作更新

空氣容量由 100 提高至 200，消耗速率不變，HUD 仍以滿容量 100% 顯示。空中減少側向噴射漂移，加入中央回正與阻尼；放開單側噴射或雙側同按時，車身轉過半圈後輔助保持水平。15 項測試通過，包含雙倍續航、中央回正及原有安全著陸流程。

## 車輛音效

新增 dist/audio.js，以 Web Audio 程序合成電動車啟動升頻、隨車速變化的馬達運轉，以及左右聲道分離的噴氣爆發與持續氣流音。沿用底部音效開關（預設開啟），首次點擊開始試駕後啟動音訊；暫停、離開頁面或關閉音效時靜音。循環音源重複使用，短音播放完畢後釋放連線。

## 噴射力學更新

以 1200 kg 車重、每噴口 4200 N 推力及 900 kg·m² 翻滾慣量計算加速度與力矩。每側控制兩噴口，雙側推力相加、噴射翻滾力矩抵銷，推力隨車體方向旋轉。移除雙噴射自動定高，持續噴射可上升，短按控高，放開下降。保留簡化滑翔升力與中央／回正輔助，並非完整真實車輛模擬。16 項測試通過。

## 著陸獎勵與碰撞演出

成功著陸且傾角小於 8 度、下降速度小於 3 m/s、翻滾角速度小於 0.5 rad/s 時，額外加 50 分並顯示完美著陸。失敗落地或撞牆會播放火花、碎片、煙霧、閃光、鏡頭震動與撞擊爆炸音，1.7 秒後顯示結果。重來會清除特效。17 項物理與評分測試通過。

## 前傾滑翔

車輛離開牆面並翻正後，飛行姿態輔助會平順調整為低頭約 6 度。噴射沿車體向上方向施力，因此產生前進與向上分量；未噴射時不額外增加前進速度。保留原有中央輔助與完美著陸門檻。18 項測試通過，含雙向飛行及三種時間步長驗證。

## 操控數值調整

空氣容量 200 → 100，滿格顯示仍為 100%；前傾噴射的前進推力乘以 0.5；翻滾慣量 900 → 450，使相同單側噴射下的翻轉加速度與穩態轉速加倍。翻正所需的單側按壓時間縮短，建議短按約 0.45 秒再改雙側調整。18 項測試通過。

## 地面接觸修正

落地改以車輪、車頂、車身、後視鏡與外輪轂的最低點判定，不再把所有姿勢的車輛中心固定在 0.72。接觸時依穿透深度抬升車體，保留碰撞前速度與姿態評分；起跑高度同步調整。跑道接觸面涵蓋地面貼圖，場外依地形頂面計算。20 項測試通過，包含不同姿勢／步長，以及實際 Three.js 模型頂點不低於地面的驗證。

## 重力難度調整

重力加速度由 9.81 提高至 12.26（約 +25%），滑翔升力與噴射力量保持原值。放開噴射下降更快，需要更早煞車；雙側噴射仍可提供淨向上推力。20 項測試通過，包含完整成功著陸及模型接地驗證。

## 特效層與噴射調整

碰撞特效群組改為場景最上方的透明效果層，繪製於跑道 Logo 之後，火焰位於煙霧前方。每噴口推力由 4200 N 提高至 4620 N（+10%），20 項測試通過。
